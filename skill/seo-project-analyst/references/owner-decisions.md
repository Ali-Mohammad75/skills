# Owner methodology decisions

Release: 0.2.0. Decisions below were explicitly settled in the owner interview through 2026-09-12. They govern this skill; all additional topics listed below were approved together. This is the owner's skill, not a separate assistant-preferred variant. Do not infer that approval of additions reverses an earlier specific choice.

## Approved methods

| ID | Operational decision | Evidence / scope distinction |
| --- | --- | --- |
| C01 | Use Indexing API selectively for owner-designated important pages, not individually for every product or all URLs. | Owner knowingly selected use beyond Google's documented JobPosting / BroadcastEvent-in-VideoObject scope. Identify this distinction, actual API acceptance and observed indexing separately. No false eligibility markup, quota bypass or indexing guarantee. |
| C02 | No six-month domain-age gate for Discover planning. | Applies to new sites too; no entry guarantee. |
| C03 | Give low CTR meaningful attention in audits and prioritization; investigate position, query/device context, snippet and page value. Low CTR/impressions alone never justify deletion/noindex. | Consider commercial role, leads/sales, backlinks, age and usefulness. Do not manufacture universal CTR cutoffs. |
| C04 | Several ranking URLs for one query trigger investigation, not automatic merge/remove/noindex. | Require actual need/intent overlap and evidence of adverse performance before such recommendations. |
| C05 | Cluster by precise user need and SERP compatibility, not broad labels such as transactional. | Owner clarified this was already the intended meaning, not a disagreement. |
| C06 | Correct/replace obsolete information, preserve useful coverage, remove irrelevant material with rationale; save baseline/version and monitor. Strikethrough is optional when useful to the reader. | Owner accepted research showing no substantiated rule that strikethrough prevents ranking loss. Never guarantee recovery or attribute every fluctuation to an edit. |
| C07 | Outbound references use the source site's name or Naked URL, not the current page's main keyword. Do not link to an external domestic-market article likely to compete with the page; relevant foreign other-language references are allowed. | A commercial/editorial preference, not a universal Google anchor rule. This restriction does not apply to internal links. Avoid inventing facts when an acceptable reference is unavailable. |
| C08 | Backlink mix and timing depend on site, goals, competition, budget and priority URLs. | Course percentages/timelines are starting examples, not quotas or calendar mandates. Paid/tier-link ideas are not silently banned or claimed compliant; distinguish policy/evidence status. |
| C09a | Content must deliver a correct, comprehensive, usable answer to the searched need, through text/image/audio/video as useful. No mandatory 300-word blocks or fixed length. | Select elements for the reader's task; do not add bulk just to satisfy a number. |
| C09b | Discover images: width exactly 1200 px as owner house specification. Normal articles: rectangular, no fixed dimensions. Landing pages: suit the individual design. | Distinguish owner's exact width from any official minimum/preview guidance; verify official requirements when needed. |
| C09c | Preserve the note's heuristic: content usually has a 72-hour life, so publish regularly to sustain Discover inflow. | Not a deadline for entering Discover, not an automatic review window and not a hard expiry. No added interpretations. |
| C09d | Entity examples explain what the teacher meant by entity. | Educational context only; not a compulsory named-entity rule for selecting a Discover topic. |
| C10a | For Iranian businesses prioritize Google Maps presence/information, then Neshan and Balad; do not routinely prescribe GBP setup there. Elsewhere check business/country eligibility. | Verify current platform availability before execution. Maps presence, GBP management and website SEO are distinct. |
| C10b | Include image geotags and Google Maps CID work in every local SEO project. | Owner-selected actions, not established guaranteed ranking factors. Use real locations and verified listing identifiers. |
| C10c | Require VPS for an operator working FROM Iran on a FOREIGN local SEO project. | Not required for every local project. Do not assume a VPS country or purpose not specified; use available authorized access and never circumvent provider controls. |
| C11 | Keep FAQ separate. Author question-and-answer comments from a visitor's perspective in natural visitor/site-response format; the owner wants these to appear like user exchanges. Owner also wants manual rating-schema increases. | Document these as owner-selected synthetic editorial/manual-rating methods, not genuine user submissions or measured votes, in the agent's work record. Do not invent source evidence, claim official endorsement or promise ranking benefit. See enrichment workflow. |

## Approved additions

All the following were disclosed as absent or insufficiently detailed in the notes, then approved together on 2026-09-12. Activate when relevant rather than forcing every task into a complete audit:

- GA4/GTM measurement, lead qualification, conversion/revenue goals and event correctness.
- Comparable GSC periods, brand/device/country segmentation, seasonality and incomplete-data handling.
- Detailed crawl/render/index diagnostics, HTTP, server logs, cache, CDN and WAF.
- Ecommerce filters, parameters, pagination, variants, stock lifecycle and sparse categories.
- Domain/URL/CMS migrations, redirect maps, rollback and regression monitoring.
- Language/country architecture, hreflang and canonical consistency.
- AI response mentions/citations and competitive visibility sampling without guarantees.
- Economic prioritization, effort/dependencies, experiments and attribution limits.
- Technical media checks including accessibility, transcripts, compression and loading.
- Scaled city/service/brand/product templates, useful distinct data and staged rollout.
- Separate private project context, execution authorization, optional tools/cost/access controls, evidence-based deliverables and work tracking.
- Modular portable packaging, documentation, versioning, behavioral evaluation, source provenance and third-party licenses.

## How to handle new material

Use the owner's original wording when identifying a conflict; do not manufacture requirements from an example, explanation or heuristic. Finish useful non-conflicting work, then ask about the specific unresolved choice. Do not claim an unpublished draft or planned action has already been deployed. Keep private project records and original course attachments outside the public package.
