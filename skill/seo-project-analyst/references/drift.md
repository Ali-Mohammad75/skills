# Before and after SEO comparison

Capture a baseline in the private project with timestamp, exact URL, response status and headers, canonical/robots/title/headings, structured data, key content and internal links where accessible. Record acquisition method, rendering mode, device, redirects, failed fetches, content hash and schema/tool versions. Preserve exact URL identity: trailing slash, parameter order and case can be significant. Do not collapse URL variants without evidence.

Compare only compatible captures. Mark new fields, missing data, changed tool/rule versions and different page coverage separately from site regressions. A changed hash alone does not prove meaningful SEO change. A previously passing title check and a newly failing robots check must remain separate even if an overall score stays constant.

Match differences to authorized changes and the project change log. Report old value, new value, evidence, affected scope, intended/unexpected/unknown status, interpretation, action and verification. A new noindex on an intentionally private page is not automatically an incident. For a suspected sitewide regression sample relevant templates before claiming sitewide scope.

This route is a manual/host-tool workflow, not an installed scheduler or persistent crawler. Use the host's scheduling feature only if requested and available.
