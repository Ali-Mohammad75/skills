# Media and scaled templates

## Images and video
Apply the full [owner enrichment checklist and image specifications](content-enrichment.md). Include audio transcripts, video subtitles and useful PDFs where relevant; distinguish proposed assets from produced and verified assets.

For an image audit inspect real HTML or rendered DOM for image URL, intrinsic dimensions, alt text, srcset/sizes, lazy loading and priority hints. Distinguish decorative from informative images. Evaluate actual LCP elements before changing lazy loading. Verify formats and delivery with responses; a file suffix does not prove decoded format or performance.

Inspect videos for crawlable landing pages, visible placement, thumbnails, accessibility and valid relevant structured data. Check current Google video requirements before promising eligibility. Do not fabricate visual inspection from text-only output. Generated product imagery must not misrepresent actual features; check applicable platform asset requirements when creating feed assets.

## Programmatic SEO
Confirm a repeatable user need and a reliable structured dataset. Define source provenance, field validation, duplicate/empty-state handling, URL rules, canonical policy, internal navigation, update cadence and page retirement. Pilot representative pages including sparse records before scaling.

Measure usefulness, indexation and business results, not only publication count. Do not use universal minimum words, uniqueness percentages or location-page counts as Google rules. Flag unsupported template claims and near-identical pages that add no useful distinction. Require authorized scope before bulk publication and prepare a reversible rollout.
