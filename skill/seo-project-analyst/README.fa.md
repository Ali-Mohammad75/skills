# راهنمای مهارت تحلیل پروژه سئو

نسخه ۰٫۲٫۰ برای استفاده مشترک در پروژه‌های مختلف سئو ساخته شده است. ساختار استاندارد مهارت دارد؛ تأیید رسمی گوگل یا OpenAI محسوب نمی‌شود.

مبنای این نسخه، یادداشت‌ها و تصمیم‌های تأییدشده صاحب اسکیل است. ترجیحات اجرایی از الزامات رسمی موتورهای جست‌وجو متمایزند. بخش‌های تکمیلی با تأیید ۱۲ سپتامبر ۲۰۲۶ اضافه شده‌اند.

## استفاده

۱. برای هر سایت، فایل `assets/project-context.md` را در فضای خصوصی همان پروژه کپی و تکمیل کن.
۲. خروجی تاریخ‌دار سرچ کنسول، کراول یا محتوای صفحات مرتبط را اضافه کن.
۳. مهارت نصب‌شده را در Work با منوی @ انتخاب کن؛ در Codex از `$seo-project-analyst` استفاده کن.
۴. کار مشخص را درخواست کن: تحلیل افت، بریف محتوا، لینک داخلی، بررسی فنی یا برنامه اقدامات.

فایل‌های این مهارت روش کار را مشخص می‌کنند؛ داده هر سایت جداست. مهارت به‌صورت خودکار به همه پروژه‌ها یا حساب سرچ کنسول دسترسی ندارد.

## انتقال و گیت‌هاب

کل پوشه را منتقل کن، نه فقط SKILL.md. راهنماها و قالب‌ها با مسیر نسبی به هم متصل‌اند. پوشه می‌تواند ریشه یک مخزن مستقل باشد یا در `skills/seo-project-analyst/` قرار بگیرد. راهنمای انگلیسی جزئیات نصب و اعتبارسنجی را دارد.

این نسخه هیچ مخزن گیت‌هابی برایت منتشر نمی‌کند. پیش از انتشار عمومی، نام و وضعیت عمومی/خصوصی مخزن و مجوز آثار اصلی خودت را تعیین کن. مجوزهای منابع دیگر در `THIRD_PARTY_NOTICES.md` حفظ شده‌اند. اطلاعات مشتری، فایل خروجی و کلید دسترسی را وارد بسته نکن.

## قابلیت‌ها و محدودیت‌ها

راهنماهای تحلیل، محتوا، لینک داخلی، تکنیکال، فروشگاهی، محلی، چندزبانه، دیسکاور، جستجوی هوش مصنوعی، سنجش فروش و برنامه‌ریزی دارد. یک ابزار Python هم برای مقایسه CSVهای استانداردشده سرچ کنسول فراهم شده است.

اتصال SE Ranking، GSC، GA4، Firecrawl و اجرای SEOmator اختیاری و وابسته به ابزار و حساب قابل دسترس است؛ در این نسخه به‌صورت اتصال آماده نصب نشده‌اند. داده ناقص نباید به نتیجه قطعی تبدیل شود.

برای اصلاح روش کار، خروجی واقعی نامطلوب را همراه با نتیجه مورد انتظار بده و بخواه راهنمای مربوط و آزمون آن اصلاح شود. نسخه جدید را بعد از اعتبارسنجی جایگزین کن.
